# Security policy

Do not commit credentials, personal data, production logs, private keys, customer payloads, or proprietary scanner reports.

The included log redactor is best-effort and is not a complete secret or personal-data detector. Review redacted output before sharing.

Skills and agents are instructions for an AI assistant, not security boundaries. Treat generated analysis as advisory. Use approved scanners, CI controls, access controls, tests, and human review for enforcement.

For suspected issues in this toolkit, report them through your organization's approved private security reporting channel.
